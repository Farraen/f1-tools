│                                                                            │

┌─ WHEN TO RUN ──────────────────────────────────────────────────────────────┐
│                                                                            │
│  ✓ After installing/updating packages                                     │
│  ✓ Before deploying to Streamlit Cloud                                    │
│  ✓ When requirements.txt is out of sync                                   │
│                                                                            │
└────────────────────────────────────────────────────────────────────────────┘

┌─ TYPICAL WORKFLOW ─────────────────────────────────────────────────────────┐
│                                                                            │
│  1. conda activate portal                                                  │
│  2. pip install new-package                                                │
│  3. python generate_requirements.py                                        │
│  4. streamlit run Home.py          # Test locally                          │
│  5. git add requirements.txt                                               │
│  6. git commit -m "Update requirements"                                    │
│  7. git push                        # Deploy                               │
│                                                                            │
└────────────────────────────────────────────────────────────────────────────┘

┌─ TROUBLESHOOTING ──────────────────────────────────────────────────────────┐
│                                                                            │
│  Package not found?                                                        │
│    → pip install package-name                                              │
│    → Run script again                                                      │
│                                                                            │
│  Wrong environment?                                                        │
│    → conda activate portal                                                 │
│    → which python  (verify)                                                │
│                                                                            │
│  Script permission denied?                                                 │
│    → chmod +x generate_requirements.py                                     │
│    → chmod +x update_requirements.sh                                       │
